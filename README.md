# Студентське портфоліо — завдання №1

Початкова адаптивна сторінка на HTML і CSS. Відкрити `index.html` у браузері.
Адреса для GitHub Pages: https://evhenii.github.io/ (публікацію ще не перевірено).

## Вимоги завдання мають пріоритет

Джерело: `Завдання №1.pdf` та чотири прикріплені зображення сторінок 1–4.
Нижче зафіксовано вимоги з наданих зображень, щоб звіряти з ними наступні зміни.

- Лише HTML5 та зовнішній CSS. Без JavaScript, фреймворків, готових шаблонів і конструкторів.
- Персональне портфоліо, щонайменше 15 змістовних `section`, кожна з власним заголовком. Заповнення має бути особистим, без Lorem ipsum.
- Семантичні елементи, один `h1`, послідовні рівні заголовків, українська мова, UTF-8, viewport, title, description, favicon, щонайменше три Open Graph метатеги.
- Таблиця з caption, thead, tbody і th scope. Змістовні alt; растрові зображення з width, height, loading="lazy"; щонайменше один picture із source media.
- Mobile first: базовий мобільний макет, лише min-width медіазапити для розмірів. Діапазон 320–1920 px, три структурно різні макети.
- Щонайменше 12 CSS-змінних у :root, кольори через змінні, відносні одиниці, clamp для тексту, h1 і h2.
- Світла/темна теми з prefers-color-scheme; Flexbox і Grid щонайменше у двох секціях, repeat(auto-fit, minmax(..., 1fr)).
- Псевдокласи hover, focus-visible, active, nth-child, not; псевдоелементи before/after; щонайменше три transition й одна keyframes-анімація з вимкненням через prefers-reduced-motion.
- Sticky-шапка, absolute/relative, плавні якорі зі scroll-margin-top, класи BEM.
- Клавіатурна доступність, skip-link, контраст тексту від 4.5:1, доречні aria-атрибути.
- W3C Validator без помилок; Lighthouse Mobile Accessibility і Best Practices від 90. Додати докази перевірок у README.
- Зображення сумарно до 3 МБ. Для фінальної версії — оптимізовані webp/avif/jpg.
- Публічний репозиторій із не менш як 8 осмисленими комітами; робоча публікація, скриншоти трьох макетів, результати W3C, Lighthouse та контрасту трьох найуживаніших пар кольорів.

## Поточна реалізація

`index.html` — header, main, 16 секцій із details/summary та footer. Перший розділ відкрито одразу. `css/style.css` — усі стилі. `img/` — локальні SVG-ілюстрації, створені для початкового макета.

Тема спочатку відповідає системній. Перемикач «Змінити тему» обирає протилежну тему через CSS :has(); працює з клавіатури клавішею пробілу. Стан не зберігається між відвідуваннями. Потрібен сучасний браузер з підтримкою :has() і ::details-content.

Форма навчальна: обов’язкові поля, email, minlength, pattern і згода перевіряються браузером. Атрибути name навмисно відсутні: введені значення не додаються до URL і не відправляються. Успішна перевірка відкриває поточну сторінку біля контактів.

## Три макети

| Ширина | Структура |
| --- | --- |
| До 768 px | Меню через details у футері, одна колонка, аватар над текстом, вертикальна галерея. |
| Від 768 px | Горизонтальна навігація у футері, дві колонки звичайних секцій і карток, аватар поруч із текстом, форма у дві колонки. |
| Від 1200 px | Усі секції по дві в рядку, крім «Про мене» на всю ширину; контакти збоку від вступу, мозаїчна галерея зі span і три колонки карток усередині секції хобі. |

Шапка прозора, без рамки, містить лише перемикач теми й залишається sticky за вимогами завдання. Навігацію перенесено у футер. Flex-колонка body з мінімальною висотою екрана та main, що займає вільний простір, тримає футер унизу короткої сторінки. Коли вмісту більше, футер іде після нього без перекриття.

Використано рекомендовані структурні пороги 768 та 1200 px. Окремий поріг 480 px не потрібен: вузький макет має гнучкі ширини й перенесення.
