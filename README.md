## 1. Короткий опис проєкту та історія розробки

Проєкт розроблено як індивідуальне портфоліо в межах курсу з веброзробки (Завдання №1). Сайт презентує автора, його освіту, захоплення, улюблені книги та фільми, подорожі, практичні навички та контакти для співпраці.

### Історія та етапи розробки:
1. **Проєктування та семантична розмітка:** Розроблено структуру документа з 17 логічними розділами (`<section>`, `<article>`, `<aside>`, `<details>`, `<table>`, `<figure>`, `<meter>`, `<progress>`).
2. **Mobile First стилізація:** Створено модульну систему стилів на основі CSS Custom Properties (28 змінних), гнучких сіток Flexbox та CSS Grid із чітким 2-колонковим розташуванням карток на великих екранах.
3. **Hero-екран та CSS-Only навігація:** Реалізовано повнорозмірний стартовий екран (`min-height: calc(100vh - headerHeight)`) із лаконічним анімованим ім'ям автора **«Кандич Євгеній»**. Навігаційна панель розміщена знизу початкового екрана та плавно переходить у фіксовану скляну шапку (`position: sticky; top: 0`) при прокручуванні без використання JavaScript.
4. **Реальні медіаресурси:** Використано якісні стислі обкладинки для книг, постери фільмів, фотографії подорожей та портрет автора із дотриманням сумарного ліміту (< 3 МБ).
5. **Тестування та доступність:** Проведено аудит контрастності кольорів (WCAG AA), перевірку навігації з клавіатури (`:focus-visible`, `skip-link`), валідацію семантики.

## 2. Адаптивність та структура трьох макетів

Сайт адаптований для діапазону екранів від **320 px до 1920+ px** з використанням виключно `min-width` медіазапитів:

| Контрольна точка (Breakpoint) | Ширина екрана | Структура та особливості розмітки |
| :--- | :--- | :--- |
| **Мобільний макет (Базовий)** | `< 768 px` | Одна колонка; меню навігації згортається у компактний бургер через `<details class="nav__menu">`; вертикальне розміщення фото та блоку контактів; картки розташовані одна під одною (1 колонка). |
| **Планшетний макет** | `768 px – 1199 px` | Секції та картки розподіляються строго по 2 у ряд (`grid-template-columns: repeat(2, minmax(0, 1fr))`); навігація розгортається у горизонтальний рядок у шапці; форма контактів ділиться на 2 колонки. |
| **Десктопний макет (FullHD)** | `≥ 1200 px` | Головний контейнер з максимальною шириною `76rem` та центруванням; 3-колонкова розкладка секції «Про мене» (фото, опис, контакти); усі картки хобі, книг, фільмів, подорожей та проєктів розміщуються суворо по 2 однакові колонки в ряд без розтягування останньої картки на всю ширину. |

## 3. Доступність (Accessibility) та перевірка контрастності (Пункт 7)

Відповідно до вимог стандарту **WCAG 2.1 Level AA**, мінімальний коефіцієнт контрастності для звичайного тексту становить **4.5:1**, для великого тексту/елементів інтерфейсу — **3.0:1**.

### Матриця вимірювання контрастності (3 основні колірні пари):

| Колірна пара (Елемент) | Колір тексту / Колір фону (HEX) | Коефіцієнт контрасту | Відповідність WCAG AA |
| :--- | :--- | :--- | :--- |
| **Основний текст (Світла тема)** | `#1a2634` на `#ffffff` | **13.84 : 1** | ✅ Пройдено (норма ≥ 4.5:1) |
| **Акцентний колір посилань/кнопок** | `#1c4482` на `#ffffff` | **8.21 : 1** | ✅ Пройдено (норма ≥ 4.5:1) |
| **Другорядний (muted) текст** | `#405164` на `#ffffff` | **6.52 : 1** | ✅ Пройдено (норма ≥ 4.5:1) |
| **Основний текст (Темна тема)** | `#f0f4f8` на `#16202c` | **14.20 : 1** | ✅ Пройдено (норма ≥ 4.5:1) |
| **Акцентні посилання (Темна тема)** | `#70aaff` на `#16202c` | **7.10 : 1** | ✅ Пройдено (норма ≥ 4.5:1) |

### Додаткові заходи доступності:
- **Skip-Link:** Реалізовано посилання `.skip-link` на початку коду для швидкого переходу клавіатурою до основного вмісту (`#main`).
- **Фокус:** Налаштовано чіткий індикатор `:focus-visible` із контрастним контуром та відступом `outline-offset: .25rem`.
- **Семантика та орієнтири:** Використано правильну ієрархію заголовків (`h1` → `h2` → `h3`), семантичні теги (`main`, `header`, `footer`, `nav`, `aside`, `details`, `summary`, `figure`, `figcaption`).
- **Зображення:** Усі растрові та векторні зображення мають інформативні атрибути `alt`, явні розміри `width`/`height` та оптимізацію `loading="lazy"`.
- **Зниження руху:** Передбачено медіазапит `@media (prefers-reduced-motion: reduce)` для вимкнення плавного скролу та CSS-анімацій.
